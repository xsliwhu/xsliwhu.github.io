# Xiaoshan Li — Academic Homepage

## 中文发布步骤

1. 登录 https://github.com/xsliwhu 。
2. 如果尚不存在，创建公开仓库 `xsliwhu.github.io`。如果已经存在，请先查看其中内容，避免覆盖已有网站。
3. 将本文件夹里的 `index.html`、`CV.pdf`、`README.md` 上传到仓库根目录（Add file → Upload files），点击 Commit changes。不要上传 ZIP 文件本身，也不要把外层文件夹作为网站根目录。
4. 打开仓库 Settings → Pages。Source 选择 Deploy from a branch；Branch 选择 main；目录选择 / (root)；点击 Save。
5. 部署成功后访问 https://xsliwhu.github.io 。可在仓库 Actions 中查看部署进度。

## 修改内容

在 GitHub 中打开 index.html，点击编辑按钮。论文在 publications 区域中，每篇论文对应一个 <li>…</li>。新增论文后提交更改，GitHub Pages 会重新部署。更新简历时，用同名 CV.pdf 替换旧文件。
